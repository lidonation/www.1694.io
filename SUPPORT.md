# Getting help

Questions about running, deploying or building on 1694.io are welcome. Please
use a public channel where possible, so that the answer helps the next person
with the same question.

## Where to ask

- **Setup and usage questions, bug reports, feature ideas** — open an issue on
  the public mirror: <https://github.com/lidonation/www.1694.io/issues>. There
  are issue templates for bug reports and feature ideas.
- **Before you open one**, please search the existing issues; the question may
  already be answered.

When asking for help with a local setup, include your operating system, your
Docker and Node versions, the component involved (`backend`, `queue-backend`,
`frontend`, or the governance indexer), the command you ran, and the full output
you got. See the [README](./README.md) for the supported setup path.

## What this repository is

The canonical repository is hosted on the project's self-hosted GitLab and is
push-mirrored to GitHub, which is public and read-only. Issues on the GitHub
mirror are read by the maintainers. Pull requests opened there are reviewed, but
are applied to the canonical repository rather than merged on GitHub — see
[GOVERNANCE.md](./GOVERNANCE.md) for why.

## Reporting a vulnerability

Do not use public issues for security problems. See [SECURITY.md](./SECURITY.md)
for the private reporting channel.

## Contributing

See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to submit a change, and
[GOVERNANCE.md](./GOVERNANCE.md) for how decisions are made.
