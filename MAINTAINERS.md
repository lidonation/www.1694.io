# Maintainers

## Project Overview

1694.io is a platform that enables technical and non-technical DReps (Cardano Delegated Representatives) to create profiles, communicate with delegators, and showcase their on-chain and off-chain activities. 
The platform was funded by Intersect MBO and originally developed by the Lido Nation team.

## Responsibilities

### Lead Maintainer Responsibilities
- Overall project direction and architecture decisions
- Review and approve major feature implementations
- Coordinate releases and version management
- Manage project roadmap and priorities
- Ensure code quality and standards compliance

### Core Maintainer Responsibilities
- Review pull requests in their area of expertise
- Maintain code quality and documentation standards
- Mentor new contributors
- Participate in technical decision-making
- Ensure proper testing and CI/CD processes

### Active Contributor Responsibilities
- Contribute code, documentation, and bug fixes
- Participate in code reviews
- Report and help resolve issues
- Follow project guidelines and standards

## Decision Making Process

1. **Minor Changes**: Any maintainer can approve and merge
2. **Major Changes**: Requires approval from at least 2 core maintainers
3. **Architecture Changes**: Requires approval from the lead maintainer
4. **Release Decisions**: Lead maintainer with input from core maintainers

## Adding New Maintainers

New maintainers are nominated by existing maintainers based on:

- Consistent, high-quality contributions to the project
- Good understanding of the codebase and architecture
- Positive collaboration with the community
- Commitment to the project's long-term success

The nomination process requires:
1. Proposal by a current core maintainer
2. Agreement from at least 2/3 of existing core maintainers
3. Acceptance by the nominee
